## P2 根因（已定位）

`HostNodes.add` 里：
```kotlin
val installId = awaitInstallId(installIds(ApiClient(active.apiBaseUrl, activeStore)), expected = null, onWaiting)
```
`installIds(client) = client.listGateways().mapNotNull { it.installId }`；服务端 `listGateways`（SoulGem `internal/httpapi/devices.go:104`）过滤 `d.owner_id=$1 AND d.state='active'`，排序 `ORDER BY d.created_at`。

`expected=null` 时取列表**第一个**，即最老的 active gateway 的 install_id。只要该服务器上有多个 active gateway 行，就可能取到旧安装的 id；对端没有该 id → 超时后返回自己的第一个 → 不等 → 抛「这个服务器上是另一台旧手机」。

**所以 P2 的环境前提：两台服务器各自只留恰好 1 个 active gateway，且是当前这台设备。**
