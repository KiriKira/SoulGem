## 1. 测试通话（三个用例全部通过）

测试通话是 Madoka「设置 → 服务器 → 测试通话」按钮：host 向 nodeA 请求一次虚拟来电，Homura 播放循环音乐（上限 30 分钟），以普通来电形式振铃 requesting host。**不需要注入真实蜂窝音频**，适合模拟器音质取数。

前置：gateway 需 `voiceReady`（`rtc_control_capabilities` 有 enabled 行）。本轮通过 adb 发 `com.callagent.gateway.START` 启动语音控制绕过诊断 UI 的 Magisk 检查（诊断要求 `CAPTURE_AUDIO_OUTPUT` 签名权限，模拟器无 Magisk 无法满足）——这是环境适配，不是产品改动。

### 1.1 普通构建 + 节点 A（`call_id=d5211a0c…`）

- 来电在数秒内到达，接听后音乐播放：`test_call_audio_ready samples=1492392 duration_ms=93274`、`test_call_playback played_s=10/20 loop=1`。
- 两端每 5–6 秒一条 `quality` 行：host `in_kbps≈32`、`out_kbps≈17`、`rx_pkts` 持续增长（219→318→306…）、`rx_lost=0`、`codec=opus/48000`、`audio_level=0.31–0.67`（有实际音频）。path=`srflx/srflx`（普通版非中继，符合预期）。

### 2.1 媒体观察（吊销后旧通话是否中断）

此项按要求**只记录、不判失败**。观察窗口 576.6 秒内共 20 个媒体样本、37 个 pending 样本：

- 两端 `path=relay/relay` 全程保持，`in_kbps/out_kbps` 双向非零，`rx_pkts` 累计从 14583→43368（gateway）、14618→43370（host）持续增长。
- `finished=false`，无自动挂断，gateway 音乐持续播放（`played_s` 到 260、loop=3）。
- 结论：**观察窗口内媒体未中断**。结合旧通话在吊销后实际又持续 13分10秒才被主动挂断，吊销未中断已建立的通话。
- “待撤销”计数：该 Worker 的管理 API 在吊销前后 `pending` 始终为 `null`（不暴露 revocations 明细），因此**无法记录“从多少降到 0”及归零时刻**——此项记为不可用，不做推断。admin 侧 admin-page 状态与上游凭据到期不能区分。

### 2.2 401 验证

带**已吊销**的 T 请求 `GET /v1/rtc/ice-servers` → HTTP **401**，`{"error":{"code":"INVALID_CREDENTIALS","retryable":false}}`（token 打码 `v1.pri***`）。这是管理机侧控制面验证；手机侧 fresh HTTP 证据本次未单独抓取，如实标注。证据见 `evidence/testcall-f2/f2-401-evidence.txt`。

### 2.3 关键发现（与需求预期不符，如实记录）

需求步骤 5 预期：吊销后手机仍用缓存凭据 → 中继建立失败、通话失败、出现 `relay_no_local_candidates`。

**实际现象**：吊销 T 后新发起的通话 `d066aba8` **仍然 relay/relay 接通并播放音乐**，未出现 `relay_no_local_candidates`。

依据：
- host：`relay_sources_resolved sources=1` → 缓存的 Worker 来源本地 UUID；`stats selected_pair=relay/relay`，rx/tx 持续增长。
- gateway：`ice_servers=2`（使用了缓存的 ICE server），`selected_pair=relay/relay`，`pcm_decoded` 持续增长。
- 该通未向 Worker 请求新凭据（否则会因 T 被吊销而拿到 401）——手机用的是缓存凭据。

解释：吊销 token 使控制面 `/v1/rtc/ice-servers` 立即返回 401（已验证），但已缓存在手机上的 TURN/ICE 凭据在其自身有效期内仍可用于建立 relay 通道。因此**吊销 token 并不立即阻断使用缓存凭据的通话**，只阻止获取新凭据。这是产品实际行为，按要求记录，不改代码。

设置页来源显示状态（吊销后）：节点来源（`<lab-ip>`）**OFF**；Worker 来源显示“已添加、ON”，`移除` 按钮可用——即吊销 UI 侧 token 后，手机上该来源条目并未被自动标记失效或移除。
